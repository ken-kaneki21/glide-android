# Glide 1.11 public source preview

This release contains reviewed source, not an installable production APK. Build it with the documented toolchain and your own local signing configuration.

- Preserve the existing Metro-inspired design with bundled OFL-licensed Selawik. Restricted personal-device Zegoe fonts and private Git history are excluded.
- Include Bluetooth/wired connection handling and simulated preview, and single-photo Original/Enhanced comparison from the private 1.11 line.
- Include original-code MIT licensing, separate dictionary CC BY-SA attribution, upstream font/wrapper notices and privacy/permission documentation.

No local AI model has been integrated. The photo processing is deterministic. No production adoption, neural restoration, universal performance gain, battery improvement or real-time model claim is made.

The private LG installation is unchanged. Public-font/device review and a dedicated production signing decision remain pending. An unsigned build is a verification artifact, not an APK to install or distribute as a finished app. Do not uninstall an existing app or force a downgrade to work around signing/version incompatibility.
